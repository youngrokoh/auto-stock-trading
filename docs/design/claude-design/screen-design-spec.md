## 승인 범위와 자료 우선순위

- 사용자는 이 문서와 연결된 클로드 화면 시안을 프로젝트의 공식 디자인 계약으로 승인했다.
- 제품 범위와 거래 안전 정책이 최우선이며, 이 문서, [디자인 시스템](../design-system.md), HTML 시안 순으로 상세 구현 근거를 사용한다.
- HTML 시안의 수치는 레이아웃 검토용 예시이며 실제 API 데이터, 기본 설정이나 거래 한도로 승인된 것이 아니다.
- 승인 상태는 디자인 방향과 화면 계약의 확정을 뜻하며 현재 React 화면의 구현 완료를 뜻하지 않는다.

## 1. 선택된 방향

`design-direction-proposals.md`의 3안 **Research Grid**를 채택했다. 세 방향을 종목 상세 화면으로 만들어 비교한 뒤 사용자가 선택했다.

- 좌측 52px 아이콘 레일 + 190~214px 네이비 내비 패널 + 밝은 격자 작업면의 3열 구조
- 모든 데이터 셀은 1px 격자로 구분하고 셀마다 좌표 라벨(A1, B2, D3)을 붙인다
- 좌표 라벨은 화면 사양 논의와 QA에서 위치를 지칭하는 공용 좌표계로 쓴다
- 실행 안전 상태는 1안(Night Watch)의 표현을 가져와 항상 주황 대비로 노출한다

## 3. 타이포그래피

| 역할 | 서체 | 크기 · 굵기 |
|---|---|---|
| 화면 제목 | Pretendard | 16px / 650 |
| 섹션 제목 | Pretendard | 14~15px / 620 |
| 본문 | Pretendard | 11.5~12px / 400 |
| 보조 설명 | Pretendard | 10~10.5px / 400, 행간 1.55 |
| 셀 좌표 라벨 | ui-monospace | 9px / 600, 자간 0.1em, 대문자 |
| 수치 | ui-monospace | 11~14px / 600 |
| 대표 수치 | ui-monospace | 20~30px / 620, 자간 -0.02em |

- 모든 숫자, 코드, 시각, 종목코드는 등폭으로 쓴다. 표에서 자릿수가 어긋나지 않게 하기 위한 규칙이다
- 종목명과 설명 문장은 Pretendard로 쓴다. 등폭 표 안에서도 이름 열만 Pretendard로 되돌린다
- 최소 크기는 9px(좌표 라벨), 읽는 문장은 10px 이상

## 4. 간격과 격자

- 데스크톱 기준 폭 1360px, 높이 908px
- 3열 구조: 아이콘 레일 52px / 내비 패널 190~214px / 작업면 나머지
- 작업면 헤더 높이 52px
- KPI 줄: `grid-template-columns: repeat(6~7, minmax(0,1fr))`, `gap: 1px`, 배경 `#d9e0ea`로 격자선을 만든다
- 카드 안쪽 여백: 헤더 `9~11px 13~18px`, 본문 `10px 13~16px`
- 표 행 세로 여백: 데이터 5~7px, 설명이 붙는 행 8~9px
- 우측 보조 열 폭 292~360px

### 4.1 세로 공간 배분

고정 높이 열에서는 다음 세 가지 역할을 구분한다.

- **고정 머리**: 섹션 헤더와 표 헤더. `flex: none`
- **가변 목록**: 행 목록. `flex: 1; min-height: 0; overflow: hidden`
- **고정 바닥**: 각주와 경고 배너. `flex: none`

`margin-top: auto`로 바닥을 밀지 않는다. 내용이 공간을 넘기면 바닥이 잘려 사라진다. 반대로 내용이 공간에 못 미치는데 `flex: 1`을 주면 빈 띠가 생긴다. 목록이 실제로 넘칠 때만 가변 영역을 만든다.

## 5. 컴포넌트

### 5.1 좌표 셀 (KPI)

```
A1 · 기준 NAV        ← 9px 등폭 라벨, #9aa8ba
38,258,400           ← 14px 등폭 620
15:24 기준            ← 9px, 값이 실시간이 아닐 때만
```

- 1px 격자로 나열하고 각 셀은 `padding: 9px 12px`
- 값을 계산할 수 없으면 `—`를 쓰고 그 아래에 이유를 적는다
- 차단 상태와 관련된 셀은 배경을 상태 색으로 바꾸고 왼쪽에 `box-shadow: inset 2px 0 0` 강조선을 넣는다

### 5.2 데이터 표

- 헤더는 9.5px 등폭 `#8b9aac`, 아래 경계 `#d9e0ea`
- 행 경계 `#f1f4f8`
- 수치 열은 우측 정렬, 이름 열은 좌측 정렬
- 종가처럼 기준이 되는 값만 `#131d2e` 600으로 강조하고 나머지는 `#3f5065`
- 주의가 필요한 행은 배경 `#fffaf1`
- 표 아래에는 단위, 출처, 기준 시각을 한 줄 각주로 붙인다

### 5.3 상태 배지

```
padding: 2px 7px; border-radius: 3px;
border: 1px solid <경계>; background: <배경>; color: <문자>;
font-size: 10px; font-weight: 600;
```

주문 상태는 체결·부분체결·거절·취소 네 가지로 표현하고, 내부 상태값(FILLED, PARTIALLY_FILLED, REJECTED, CANCELED)과 1:1로 대응시킨다.

### 5.4 경고 배너

세 단계로만 쓴다.

| 단계 | 배치 | 자동 해제 |
|---|---|---|
| 정보 · 회색 | 해당 영역 안 | 해당 없음 |
| 주의 · 주황 | 작업면 헤더 바로 아래 전체 폭 | 조건에 따라 허용 |
| 위험 · 적색 | 작업면 헤더 바로 아래 전체 폭 | 없음 |

배너 구성은 아이콘 38px + 제목 + 사유 코드 배지 + 설명 + 행동 버튼 + 단서 문장이다. 배너 하단에 `box-shadow: inset 0 -3px 0 <강조색>`을 넣어 아래 내용과 분리한다.

### 5.5 진행·소진율 막대

```
height: 3~5px; border-radius: 2px; background: #eef1f6;
채움: #1f6feb (정상) / #d99b3c (주의) / #d33a2c (85% 초과)
```

라벨 줄에 현재값과 한도를 `현재 / 한도` 형태로 함께 쓴다.

### 5.6 차트

- 캔들: 상승 `#d33a2c`, 하락 `#2563a8`, 심지 폭 1px
- 이동평균: MA5 `#c77b28`, MA20 `#1f7a6a`, MA60 `#7a6a9c`, 굵기 1.2px
- 가격축 눈금은 SVG 밖 HTML 요소로 배치한다. `preserveAspectRatio="none"`으로 늘어난 SVG 안에서는 텍스트가 함께 왜곡된다
- 범례는 차트 위에 두고 이름과 현재값을 함께 쓴다
- 데이터가 오래된 차트는 `opacity: 0.55; filter: grayscale(1)`
- 데이터가 없는 구간은 음영과 점선 경계로 표시하고 값을 만들지 않는다

## 7. 상태 표현 규칙

### 7.1 원칙

1. 없는 값은 추정해 채우지 않는다. 무엇이 없는지와 기준 시각을 쓴다
2. 차단은 사유 코드로 식별하며 화면과 감사 로그가 같은 코드를 쓴다
3. 차단 상태에서도 조회는 막지 않는다. 막는 것은 주문 생성이다
4. 자동 재개는 데이터 신선도처럼 기계적으로 판정되는 경우에만 허용한다
5. 보유 포지션을 자동으로 청산하는 오류 처리는 없다
6. 부분 실패는 화면 전체를 덮지 않고 해당 행에만 표시한다

### 7.2 차단 사유 코드

| 코드 | 의미 | 표현 | 해제 |
|---|---|---|---|
| `API_CONSECUTIVE_FAILURE` | 5분 내 외부 API 3회 실패 | 적색 전체 배너 | 사용자 확인 후 재개 |
| `ACCOUNT_NOT_RECONCILED` | 내부 기록과 증권사 잔고 불일치 | 주황 전체 배너 + 차이 표 | 재조정 성공 |
| `DATA_STALE` | 기준 데이터가 허용 지연 초과 | 주황 전체 배너 + 값 회색 처리 | 수집 성공 시 자동 |
| `SYMBOL_SUSPENDED` | 거래정지·주문 불가 종목 | 적색 인라인 배너 | 거래 재개 시 자동 |
| `MARKET_CLOSED` | 주문 허용시간 밖 | 헤더 상태 표시 | 허용시간 진입 시 자동 |
| `SOURCE_TIMEOUT` | 외부 데이터 출처 응답 없음 | 해당 행 주황 배경 | 해당 작업만 재시도 |

위험 한도에 의한 주문 거절 코드(`RISK_*`)는 별도 체계이며 모의매매 콘솔과 감사 로그에서 동일하게 사용한다.

### 7.3 빈 상태

| 종류 | 표현 | 행동 |
|---|---|---|
| 조건에 맞는 결과 없음 | 흰 배경, 실선 카드 | 필터 초기화 |
| 아직 만들지 않음 | 흰 배경, 실선 카드 | 만들기 버튼 하나 |
| 단계 미도달 | `#fafbfd` 배경, 점선 경계 | 없음. 안내만 |

행동 버튼은 최대 하나만 둔다.

### 7.4 오래된 값 표기

- 값 색을 `#8b9aac`로 낮춘다
- 값 옆이나 아래에 기준 시각을 붙인다
- 파생 값(등락률, 손익)은 계산하지 않고 `—`로 둔다
- 확정되지 않은 봉은 표에서 행을 구분하고 보조지표 계산에서 제외한다

### 8.5 전환 규칙

- 레이아웃, 간격, 좌표 라벨, 글자 크기는 두 모드가 완전히 동일하다. 색만 바뀐다
- 기본값은 시스템 설정을 따르고, 설정 화면에서 라이트·다크·시스템 세 가지로 고정할 수 있다
- 상승 적색과 하락 청색은 두 모드 모두 유지한다. 색맹 대응 팔레트는 별도 설정으로 다룬다
- 차단 배너는 두 모드 모두 같은 위치, 같은 의미 색 계열을 쓴다. 값만 대응표를 따른다
- 기존 `frontend/src/styles.css`는 이미 `color-scheme: dark` 기준이므로 라이트 값을 추가하는 방향으로 확장한다
- 적용 범위: 시안 8a(종목 상세), 8b(모의매매 콘솔). 나머지 화면은 대응표를 기계적으로 적용한다

## 9. 모바일

- 기준 폭 390px
- 하단 탭 5개, 각 항목 최소 높이 44px

- 파괴적 행동(비상정지)은 최소 높이 44px 이상, 다른 버튼과 색으로 구분

## 10. 시인성 기준

- 본문 대비 4.5:1 이상, 라벨과 보조 문자 3:1 이상
- 상태를 색만으로 구분하지 않는다. 아이콘, 코드, 문구 중 최소 하나를 함께 쓴다
- 슬라이드가 아닌 밀집 화면이므로 행 높이를 줄이는 대신 열 사이 여백을 확보한다
- 수치 열은 우측 정렬과 등폭으로 자릿수를 맞춘다
