## 1. Atmosphere & Identity

이 화면은 투자 수익을 과장하는 트레이딩 터미널이 아니라 자동매매 시스템의 안전 상태를 확인하는 운영 콘솔이다. 차분한 흑연색 배경, 낮은 채도의 청록색 정상 상태, 명확한 주황색 경고를 사용한다. 가격·수익률 데이터가 없는 단계에서는 차트 모양의 장식이나 임의 숫자를 표시하지 않는다.

핵심 인상은 `신뢰할 수 있음`, `절제됨`, `검증 가능함`이다. 실전거래 비활성 상태는 항상 첫 화면에서 확인할 수 있어야 한다.

## 2. Color

### Palette

| 토큰 | 값 | 용도 |
|---|---|---|
| `--color-canvas` | `#080b0f` | 최상위 배경 |
| `--color-panel` | `#0e1319` | 패널 배경 |
| `--color-panel-raised` | `#141b22` | 상호작용 표면 |
| `--color-line` | `#25303a` | 구분선 |
| `--color-text` | `#f2f6f8` | 주요 텍스트 |
| `--color-text-muted` | `#91a0ab` | 보조 텍스트 |
| `--color-accent` | `#48d4c4` | 정상·선택 상태 |
| `--color-accent-soft` | `#123934` | 정상 상태 배경 |
| `--color-warning` | `#ffb454` | 안전 경고 |
| `--color-warning-soft` | `#392817` | 경고 배경 |
| `--color-danger` | `#ff746c` | 오류·위험 |
| `--color-focus` | `#7ee7dc` | 키보드 포커스 |

구현에서는 위 핵심 팔레트를 `surface`, `border`, `text`, 상태별 semantic 토큰으로 확장한다. 컴포넌트 CSS는 색상 리터럴을 직접 사용하지 않고 이 semantic 토큰만 참조한다. 간격·글자 크기·모서리·터치 대상도 각각 `--space-*`, `--font-size-*`, `--radius-*`, `--size-touch` 토큰으로 관리한다.

색은 의미를 보조하며 단독으로 상태를 전달하지 않는다. 모든 상태에는 텍스트와 아이콘 또는 형태 차이를 함께 제공한다. 본문 대비는 WCAG AA 이상을 유지한다.

## 3. Typography

### Scale

| 역할 | 크기/행간 | 굵기 |
|---|---|---|
| 화면 제목 | `1.75rem/1.2` | 650 |
| 섹션 제목 | `1rem/1.35` | 600 |
| 본문 | `0.875rem/1.55` | 400 |
| 메타·라벨 | `0.75rem/1.4` | 500 |
| 숫자 상태 | `1.125rem/1.25` | 620 |

### Font Stack

로컬 시스템 글꼴만 사용한다: `Pretendard`, `Apple SD Gothic Neo`, `Noto Sans KR`, `system-ui`, `sans-serif`. 숫자와 코드 값에는 `SFMono-Regular`, `Consolas`, `monospace`를 사용한다. 외부 폰트 요청을 만들지 않는다.

## 4. Spacing & Layout

- 기본 단위: 4px
- 주요 간격: 8, 12, 16, 24, 32px
- 데스크톱: 224px 내비게이션과 유동 작업 영역
- 태블릿: 상단 내비게이션으로 전환하고 패널을 2열로 배치
- 모바일: 1열, 좌우 16px 여백, 핵심 안전 상태를 콘텐츠보다 먼저 표시
- 전체 화면 셸은 `100dvh`를 사용하고 스크롤 소유자는 주 작업 영역 하나로 제한한다.
- 콘텐츠 최대 폭은 1440px이며, 서비스 상태 영역은 최소 280px에서 자연스럽게 줄바꿈한다.

## 5. Components

### App shell

브랜드 텍스트, 현재 단계, 주요 내비게이션과 하단 환경 표시를 포함한다. 미래 단계 메뉴는 비활성 상태와 `준비 중` 문구를 제공하며 클릭 가능한 것처럼 보이지 않아야 한다.

### Status badge

`정상`, `확인 필요`, `연결 중`, `사용 안 함` 네 상태를 지원한다. 28px 이상의 높이, 텍스트 라벨, 8px 상태점을 사용한다.

### Service row

서비스명, 역할, 상태를 한 행에 표시한다. 응답시간·연결 수처럼 백엔드가 제공하지 않는 지표는 만들지 않는다. 로딩 시에는 폭이 고정된 스켈레톤을, 실패 시에는 원인 범주와 재시도 동작을 제공한다.

### Safety notice

모의투자와 실전거래 상태를 분리해 보여준다. 실전거래 비활성 경고는 주황색 경계와 잠금 아이콘, 명시적 문구를 함께 사용한다.

### Empty module

아직 데이터가 없는 전략·주문·포지션 영역은 설명과 해당 기능이 열리는 단계를 표시한다. 임의 차트, 수익률 또는 건수를 채우지 않는다.

### Table, chart and filter contract

- 표: 헤더 고정은 실제 세로 스크롤이 있을 때만 사용한다. 숫자는 우측 정렬하고 단위·기준시각을 헤더에 표시한다.
- 차트: 색상 외에 선 형태·범례로 시리즈를 구분하고, 키보드로 데이터 요약을 읽을 수 있어야 한다.
- 필터: 적용 중인 조건과 초기화 동작을 항상 노출한다. 시장·상품 유형·기간을 숨은 기본값으로 두지 않는다.
- 오류: 오류 범주, 영향 범위, 마지막 정상 시각, 재시도 가능 여부를 표시한다. 자격증명이나 원문 응답은 표시하지 않는다.

## 6. Motion & Interaction

- 짧은 상태 변화: 120ms
- 패널·내비게이션 전환: 180ms
- 로딩 상태는 반복 회전 장식보다 낮은 대비의 펄스를 사용한다.
- `prefers-reduced-motion`에서는 변형과 반복 애니메이션을 제거한다.
- hover는 포인터 장치에서만 보조 신호로 사용하고, 키보드 포커스는 2px 외곽선으로 항상 보인다.

## 7. Depth & Surface

깊이는 그림자보다 배경 명도와 1px 경계로 구분한다. 기본 패널은 그림자를 쓰지 않고, 떠 있는 메뉴나 툴팁에만 짧고 낮은 그림자를 허용한다. 모서리 반경은 패널 12px, 제어 8px, 상태 배지 999px로 제한한다. 유리 효과, 과도한 그라디언트, 장식용 3D 효과는 사용하지 않는다.

## 8. Accessibility Constraints & Accepted Debt

### Constraints

- 모든 기능은 키보드로 접근 가능해야 하며 논리적인 포커스 순서를 유지한다.
- 375px, 768px, 1280px 너비에서 가로 페이지 스크롤이 없어야 한다.
- 터치 대상은 최소 44x44px을 목표로 한다.
- 상태·오류·안전 경고는 스크린리더가 읽을 수 있는 텍스트를 포함한다.
- 로딩 완료와 연결 오류는 적절한 live region으로 알린다.
- 브라우저 번들에는 API 키, 계좌번호, 데이터베이스·Valkey 주소를 넣지 않는다.

### Accepted Debt

- 1단계에는 실제 표와 차트 데이터가 없으므로 규칙과 빈 상태만 구현한다.
- 다국어 전환과 사용자 테마 선택은 초기 범위에서 제외한다.
- 고급 밀도 설정과 단축키 도움말은 실제 시장 데이터 화면이 생기는 3단계에서 검토한다.
