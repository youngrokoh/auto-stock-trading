# ADR-0012: ML 신호의 전략 경계

- 상태: 승인
- 결정일: 2026-08-21
- 관련 결정: [ADR-0004 AI 신호와 주문 실행 분리](0004-ai-execution-separation.md)
- 관련 계약: [ML 신호 데이터·모델 계약](../data/ml-signal-contract.md), [백테스트·규칙형 전략 계약](../data/backtest-strategy-contract.md)
- 관련 정책: [거래 안전 정책](../spec/trading-safety-policy.md), [모의투자·실전투자 전환 게이트](../spec/paper-to-live-gate.md)
- 관련 로드맵: [구현 로드맵](../plan/implementation-roadmap.md) 8단계

## 배경

[ADR-0004](0004-ai-execution-separation.md)는 AI 출력이 주문 API에 직접 닿지 못하게 했다. 그
경계는 유지된다. 이제 8-2 단계에서 **실제 ML 신호가 전략 계층에 들어온다**. 새로 필요한 경계는
주문 쪽이 아니라 **평가 쪽**이다.

로드맵의 8단계 완료 기준은 "규칙형 기준 전략보다 표본 밖 거래비용 후 성과가 개선된다"이다. 이
기준을 판정하려면 비교 대상인 규칙형 전략이 ML 도입 후에도 **바뀌지 않은 상태로** 남아 있어야
하고, 성과 차이가 신호 차이에서만 와야 한다. 또한 모델은 학습 기간을 갖기 때문에, 백테스트 창과
학습 창이 겹치면 표본 밖 성과가 아니게 된다. 규칙형 전략에는 없던 실패 모드다.

## 결정

1. **ML 신호는 별도 전략 이름으로만 실행한다.** 전략 이름은 `ml-rank`이며 기존 `cross-momentum`
   (v2)·`composite-rank`(v3)의 정의·파라미터·기록을 바꾸지 않는다. 종합 순위에 ML 점수를 요인으로
   섞지 않는다.
2. **엔진·비용·체결 모형은 공유한다.** ML 전략도 `run_portfolio_backtest`와 안전 정책 §5 비용
   규칙을 그대로 쓰고, 회차 생성기만 교체한다. 엔진이 다르면 성과 차이의 원인을 신호로 좁힐 수 없다.
3. **추론은 저장된 모델 버전으로만 한다.** 백테스트 실행 기록에 모델 ID와 특징 정의 버전을
   남긴다. 실행 시점에 모델을 새로 학습하지 않는다.
4. **학습 창과 백테스트 창이 겹치면 실행을 거부한다**(`train_window_overlap`). 겹친 실행을
   완주시켜 성과를 보고하면 그것이 표본 밖 성과로 오독된다.
5. **모델이 없어도 시스템 전체가 동작한다.** 모델 없이 `ml-rank`를 실행하면 실패 코드로 거부되고,
   규칙형 전략·수집·주문 경로는 영향을 받지 않는다.
6. **ML 신호는 7단계 주문 계획에 연결하지 않는다.** 연결은 모의투자 그림자 운용으로 실제 체결
   기준 성과를 확인한 뒤 별도 ADR로 결정한다. 이 ADR은 백테스트 계층까지만 허용한다.
7. **ML 신호도 위험검사를 우회하지 못한다.** ADR-0004의 흐름(신호 → 목표 포지션 → 결정적
   위험검사 → 주문)은 그대로다.

## 대안

### 종합 순위에 ML 점수를 네 번째 요인으로 추가

기대 성과는 높을 수 있으나 AI 기여를 분리해 측정할 수 없다. 로드맵 완료 기준이 "규칙형 대비
개선"이므로 기준 자체가 움직이면 판정이 불가능해진다. 기각한다.

### 학습·추론을 한 실행에서 수행

편리하지만 창 겹침을 구조적으로 막을 수 없고, 실행마다 모델이 달라져 재현성이 깨진다. 기각한다.

### ML 신호를 바로 모의주문에 연결

체결 기준 성과가 없는 상태에서 자금이 움직인다. 안전 정책의 단계적 확대 원칙과 어긋난다. 기각한다.

## 결과

- 규칙형 기준선(v2·v3)이 비교 대상으로 보존된다.
- 실행 기록에 모델·특징 버전이 남아 "왜 결과가 달라졌는지" 설명할 수 있다.
- 창 겹침이 구조적으로 차단되어 표본 밖 성과라는 주장이 검증 가능해진다.
- ML 전략과 규칙형 전략이 같은 읽기 API·화면에서 나란히 조회된다.
- 그림자 운용과 주문 연결은 후속 결정으로 남는다.

## 재검토 조건

ML 신호를 주문 계획에 연결하려면 이 ADR을 개정하지 않고 **새 ADR**을 만든다. 이 결정은 백테스트
계층의 경계를 정의하며, 주문 연결은 별도의 안전 판단을 요구한다.
