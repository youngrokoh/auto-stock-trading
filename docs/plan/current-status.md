## 반드시 기억할 디자인 상태

현재 웹 화면은 기능과 실행 환경을 검증하기 위해 구현한 프로토타입이다.

- 사용자는 2026-08-12에 [클로드 화면 디자인 사양](../design/claude-design/screen-design-spec.md)과 [HTML 시안](../design/claude-design/screen-mockups.html)을 공식 디자인 방향으로 승인했다.
- 승인 방향은 Research Grid 골격, 라이트·다크 대응과 Night Watch의 안전 상태 강조를 결합한다.
- 현재 React 프로토타입은 승인 디자인 구현 전이다. 기존 화면의 QA 통과를 승인 디자인 구현 완료로 해석하지 않는다.
- 시안의 가격, 수익률, 계좌, 주문과 포지션 숫자는 레이아웃 예시이므로 하드코딩하지 않는다.
- 실제 구현은 [디자인 시스템](../design/design-system.md)의 토큰과 화면 사양의 재사용 프리미티브를 먼저 반영한다.
- 백엔드와 인프라 기반은 승인 여부와 무관하게 계속 사용할 수 있다.

## 진행 중인 작업: 2단계 KIS 시장 데이터 기반

2026-08-14에 첫 수직 슬라이스의 코드와 자격증명 없이 실행 가능한 검증을 구현했다.

1. 완료: 접근 토큰 발급·캐시·만료 갱신과 최소 호출 간격을 처리하는 KIS 어댑터
2. 완료: append-only 원본 응답과 멱등 정규화 데이터를 분리한 PostgreSQL 스키마
3. 완료: 삼성전자와 KODEX 200의 종목정보·현재가·비수정 일봉 수집 작업
4. 완료: 실패 복구와 반복 수집을 검사하는 fixture·PostgreSQL 통합 테스트
5. 완료: 출처와 기준시각을 포함한 읽기 전용 API
6. 완료: 사용자가 모의·실전 KIS 키를 발급했으며 실전 키는 검증 경로에서 분리
7. 완료: 모의투자 초당 1건 제한, Docker secret 전달과 반복 검증 런북 준비
8. 완료: 사용자의 로컬 모의 키로 외부 호출, 반복 수집, DB·읽기 API와 원본 보안 검증
9. 대기: 사용자가 KIS 모의투자 화면의 값과 거래일을 최종 육안 대조
10. 완료: 사용자가 2026-08-14 승인한 [ADR-0005](../decisions/0005-kis-token-and-rate-coordination.md)의 Valkey 기반 프로세스 간 토큰 재사용과 분산 호출 게이트를 구현하고 실제 모의환경에서 재발급 없는 독립 worker 수집 검증
11. 완료: [국내 시장 달력 데이터 계약](../data/market-calendar-data-contract.md)에서 거래일·휴장일·단축장, 사실 버전과 당일 확인 상태 정의
12. 완료: 시장 달력 Alembic 마이그레이션·도메인·PostgreSQL 저장소와 정상·휴장·단축장, 정정 버전, 출처 충돌, 다음·이전 거래일 통합 검증
13. 완료: KRX 공식 휴장일 연간 응답 수집·원본 공유·범위 원자 저장과 KIS `CTCA0903R` 당일 보완 확인 연결
14. 완료: KRX 보도자료 목록·공식 PDF에서 수능일·연초 개장일의 주식·ETF 임시 정규장 시간을 수집하고 연간 일정과 원자적으로 합성
15. 대기: KIS 당일 확인의 실제 실전 자격증명 검증
16. 구현 대기: 사용자가 2026-08-16 승인한 [ADR-0006](../decisions/0006-market-calendar-scheduling.md)에 따라 시장 달력 단일 scheduler, PostgreSQL 실행 claim과 단계별 활성화를 구현
17. 후속: 분봉, 기업행사·수정주가 데이터셋

자격증명은 문서, Git, 브라우저 번들과 로그에 기록하지 않는다. 실전 주문 기능은 이 단계에 포함하지 않는다.

## 권장 진행 순서

```text
디자인 방향 제안·사용자 승인 (완료)
    ↓
KIS 모의 키 로컬 secret 입력
    ↓
실제 KIS 모의환경 반복 수집·API 대조 (완료)
    ↓
프로세스 간 토큰 재사용 (완료) · KIS 화면 육안 대조 (사용자 대기)
    ↓
시장 달력 데이터 계약 (완료)
    ↓
시장 달력 저장·조회 구현 (완료)
    ↓
KRX 일정 수집·당일 보완 확인 연결 (구현 완료, KIS 실전 호출 대기)
    ↓
KRX 임시 거래시간 공지 수집·연간 일정 합성 (완료)
    ↓
시장 달력 scheduler 실행 계약 ADR 승인 (구현 대기)
    ↓
2단계 분봉·기업행사
    ↓
승인된 디자인으로 3단계 시장 대시보드 구현
```

## 다음 기술 작업 완료 조건

시장 달력의 마이그레이션, 도메인 타입, PostgreSQL 저장소, KRX 공식 연간 휴장 일정·임시 거래시간 공지 수집과 KIS 당일 보완 확인 경계를 완료했다. 다음 기술 작업은 승인된 [ADR-0006](../decisions/0006-market-calendar-scheduling.md)에 따라 단일 scheduler, PostgreSQL 실행 claim과 단계별 활성화를 구현·통합 검증하는 것이다. 별도 실전 자격증명 검증 전까지 KIS 당일 확인은 fixture 계약만 통과했으며 모의환경에서는 fail-closed로 차단한다. 그다음 분봉, 기업행사·수정주가를 구현한다. 사용자는 별도로 KIS 화면의 값과 거래일을 최종 육안 대조한다. 승인 디자인 구현 세션에서는 공통 프리미티브와 대상 화면이 390px, 768px, 1360px 실제 브라우저 QA를 통과해야 한다.
