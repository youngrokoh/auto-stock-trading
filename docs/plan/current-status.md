## 반드시 기억할 디자인 상태

- 사용자는 2026-08-12에 [클로드 화면 디자인 사양](../design/claude-design/screen-design-spec.md)과 [HTML 시안](../design/claude-design/screen-mockups.html)을 공식 디자인 방향으로 승인했다.
- 2026-08-17에 승인 토큰·프리미티브(좌표 셀, 데이터 표, 상태 배지, 경고 배너, 반응형 앱 셸)와 운영 개요(`/`), 시장 데이터(`/market`), 구성요소 갤러리(`/showcase`)를 승인 디자인으로 구현했고 390·768·1360px 실브라우저 QA를 통과했다([3단계 검증](../qa/phase-3-market-dashboard-verification.md)). 태블릿 접기 규칙은 같은 날 사용자가 확정했다(레일 유지·내비 숨김·1열·KPI 3×2).
- 시안의 가격, 수익률, 계좌, 주문과 포지션 숫자는 레이아웃 예시이므로 하드코딩하지 않는다. 모든 표시 값은 실제 API에서 오고, 백엔드가 없는 영역은 값 생성 없이 빈 상태 규칙으로 표시한다.
- 이후 화면(기업 분석, ETF 탐색, 전략 연구, 모의매매 콘솔 등)도 같은 토큰과 프리미티브로 확장한다.

5. 완료: 출처와 기준시각을 포함한 읽기 전용 API
6. 완료: 사용자가 모의·실전 KIS 키를 발급했으며 실전 키는 검증 경로에서 분리

건너뛰었다. 실수집에서 발견한 두 가지(자본변동표 `ord` 중복, `account_id` 최대 180자)는 사용자 승인으로 계약을 정정해 반영했다(`line_seq` 유일키, `VARCHAR(255)`). 이어 사용자가 승인한 재무 지표 정의 계약(연결·연간 사업보고서 기준, 같은 보고서의 당기·전기 금액만 사용, ROE 지배주주 기준, 가치지표는 상장주식수 정규화 수집 후 후속)에 따라 성장성 3종·수익성 4종·안정성 2종을 백엔드가 조회 시점에 계산하는 읽기 API를 구현했다. 응답은 지표마다 수식·입력 계정과 금액·근거 접수번호를 포함하고, 필요한 계정이 없으면 값 없이 사유 코드를 담는다(개별 재무제표의 ROE가 실제로 `MISSING_ACCOUNT`). 실제 삼성전자 연결 5개년 지표를 DART 원문 금액 수동 재계산과 대조했다(2025 매출액증가율 10.88%, 영업이익률 13.07%, 부채비율 29.94% 등). 승인 디자인 기업 분석 화면(`/analysis`)은 KPI 7셀, 실적 막대 차트, 원문 재무제표 라인 표(보고서·구분 전환), 연도별 지표 표와 근거 공시 카드를 이 API로만 구성하고 가치지표·수급·공시 연결은 빈 상태로 두었으며, e2e 12건과 390·768·1360px·다크 실브라우저 QA를 통과했다. 이어 사용자가 승인한 가치지표 정정 계약에 따라 상장주식수를 KIS 시세 수집에서 함께 관측해 `reference.listed_share_count` 버전 사실로 저장하고(같은 값 재관측 멱등, 값 변경은 이력 보존 새 버전), 가치지표 `valuation` 블록을 구현했다. EPS는 공시 기본주당이익 원문을 그대로 쓰고(파생 EPS는 우선주 미반영 왜곡으로 계산하지 않음), PER = 현재가 ÷ 최근 연간 기본주당이익, 시가총액 = 현재가 × 보통주 상장주식수이며 응답은 가격·주식수·재무 기준을 항상 분리해 명시한다. 실수집으로 삼성전자 5,846,278,608주를 적재해 PER 41.56배·시가총액 1,604,803,477,896,000원을 수동 계산과 대조했고, KIS가 제공하는 per/pbr 외부 계산값은 노출하지 않는다. BPS·PBR은 우선주 반영 설계 확정 시 후속이다. 이어 사용자가 승인한 수급·공시 연결 계약에 따라 KIS 투자자별 매매(일별 개인·외국인·기관 순매수 수량·대금)를 서울 기준 당일을 제외한 버전 사실로 저장하고(실측 한계 기록: 세 주체 합 ≠ 0, 대금 백만원 단위, 최근 30거래일만 제공되어 수집 시점부터 축적), DART 공시 목록을 주요 유형별(정기 A·주요사항 B·지분 D·거래소 I)·접수번호 유일 불변 사실로 최근 1년 수집했다. 실수집으로 삼성전자·KODEX 200 수급 각 30거래일과 삼성전자 공시 2,837건을 적재했고 재수집은 멱등이며 KIS 원본 응답 값과 일치했다. 읽기 API 두 개와 기업 분석 D2(최근 8거래일 순매수 표)·D3(공시 목록과 DART 원문 링크) 카드를 구현해 4단계 화면 좌표(2b)가 전부 실제 값으로 채워졌다. 이어 사용자가 승인한 ETF 탐색 데이터 계약에 따라 KIS 공식 마스터 파일(비인증 고정폭 레코드)에서 KOSPI ETF 1,163종목을 버전 사실로 적재하고, ETF 현재가(FHPST02400000)의 원본 필드(NAV·괴리율 dprt·추적오차·추적배수·운용사·대표지수·순자산총액 억원)를 최신 스냅샷으로 전량 수집했다(개별 종목 실패는 기록 후 계속, 회당 약 21분). 분배율은 로드맵 수식(최근 12개월 분배금 합 ÷ 현재가 × 100)으로 분배금 이력 보유 ETF만 계산한다. 목록·상세 읽기 API와 승인 시안 3a의 ETF 탐색 화면(요약 KPI·순위표·투자자별 순매수·선택 상세)을 구현했고 순위는 등락률·거래량·괴리율·추적오차·순자산의 스냅샷 지표만 제공한다(거래대금·기간수익률·투자자별 순위는 후속). 이어 사용자가 승인한 백테스트·규칙형 전략 계약에 따라 6단계 1차를 구현했다. KIS 모의환경 기간별시세로 일봉을 2025-01-02부터 구간 분할 백필·재관측 확정해 종목당 394거래일을 확보했고, 삼성전자 2025년 배당 4건을 DART에서 소급 수집해 3건을 검증 락일로 확정했으며(2024년 기준일 1건은 달력 미커버로 계약대로 pending), `total_return` 수정주가 데이터셋을 전체 창으로 재발행했다. 결정적 백테스트 엔진은 T 마감 신호를 다음 거래 가능일 시가에 체결하고(주말·휴장 이월 확인), 안전 정책 §5 비용과 연도별 법정 매도세 버전(`research-krx-2025`·`2026`)을 적용하며, 검증 락일에 배당 현금을 반영하고, 모든 신호를 접두 시계열 재계산으로 검사해 미래정보 참조를 거부한다. 이동평균·RSI 전략 실행 2건(삼성전자 +44.35%, KODEX 200 +10.60%, 벤치마크 +254.49%는 원본 시세 그대로)의 재현성과 신호 107건 독립 재계산 일치를 검증했고, 실행 기록은 `strategy` 스키마에 저장되어 `/api/backtests`로 조회된다. 같은 날 승인 시안 2c의 전략 연구 화면을 구현해 저장된 실행 기록·체결·NAV 곡선·입력 계보가 전부 실제 API 값으로 표시되고, D 좌표는 사용자 승인으로 신호·체결 기록을 표시하며 목표 포지션 변환은 7단계에서 확장한다. 종합 순위·ETF 모멘텀 전략(유니버스 확장)은 후속이며, KIS 수정주가 대조는 분할 이력 종목 확보 시 수행한다. 다음 기술 작업은 7단계 모의투자 자동매매다. 기본 Compose와 모의환경은 계속 KIS 자동 확인이 꺼져 있고 실전 달력 전용 worker만 자격증명을 받는다. 사용자는 별도로 KIS 화면의 값과 거래일을 최종 육안 대조한다. 승인 디자인 구현 세션에서는 공통 프리미티브와 대상 화면이 390px, 768px, 1360px 실제 브라우저 QA를 통과해야 한다.
