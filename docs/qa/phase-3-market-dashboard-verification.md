# 3단계 시장 대시보드 검증

- 상태: 검증 완료 (1차 구현 범위)
- 검증일: 2026-08-17
- 관련 계약: [화면 디자인 사양](../design/claude-design/screen-design-spec.md), [디자인 시스템](../design/design-system.md)
- 관련 API: [시장 데이터 읽기 API](../api/market-data-api.md)

## 구현 범위

승인된 Research Grid + Night Watch 디자인의 토큰과 프리미티브(좌표 셀, 데이터 표, 상태 배지, 경고 배너, 반응형 앱 셸)를 구현하고 세 화면을 재구축했다.

| 화면 | 경로 | 내용 |
|---|---|---|
| 운영 개요 | `/` | 상태 KPI 6셀, 서비스 상태, 수집 파이프라인(실제 종목·시세 기준시각), 실전 전환 게이트, 안전 경계, 이벤트 빈 상태 |
| 시장 데이터 | `/market` | 종목 전환(수집 종목 목록 API), 기간 전환(1·3·6개월·전체), 시세 KPI, 캔들·거래량·RSI·MACD·볼린저 차트, OHLCV 표, 종목 정보, 기업행사(실제 배당·분배 이력), 수급·신호 빈 상태 |
| 구성요소 갤러리 | `/showcase` | 프리미티브 상태 계약 |

모든 값은 실제 백엔드 API에서 온다. 시안의 가격·계좌·주문 값은 사용하지 않았고, 계좌·주문·수급·이벤트처럼 백엔드가 없는 영역은 값 생성 없이 빈 상태 규칙으로 표시한다. 시세는 배치 수집 값이므로 KPI에 기준시각과 `지연 데이터` 상태 셀을 항상 노출하고, 미확정(pending) 일봉은 보조지표 계산에서 제외하며 표에서 행을 구분한다.

## 실제 브라우저 QA (2026-08-17)

Playwright Chromium으로 390×844, 768×1024, 1360×908 세 폭에서 실행했다.

| 항목 | 결과 |
|---|---|
| e2e 9건 (운영 개요·시장 데이터·갤러리 × 3폭) | 전부 통과 |
| 콘솔 오류 0건, 가로 페이지 스크롤 없음 | 세 폭 모두 확인 |
| 연결 문자열 부재 (`postgresql://`, `redis://`) | 본문 텍스트에서 부재 확인 |
| 1360px | 3열 셸(레일 52px + 내비 + 작업면), KPI 6셀, 주 열 + 316px 보조 열, 좌표 라벨 표시 |
| 768px (사용자 확정 규칙) | 레일 유지·내비 숨김, 1열 접기, KPI 3×2 |
| 390px | 하단 탭 5개(최소 44px), KPI 2×3, OHLCV 표가 카드 목록으로 접힘, 주의 배너 상단 고정 |
| 다크 모드 | `prefers-color-scheme: dark`에서 사양 8절 대응표 색상으로 렌더링 확인 |
| 실데이터 대조 | 시세 KPI·수집 파이프라인 기준시각이 DB `received_at`과 일치, 기업행사 카드가 검증된 배당 3건(삼성전자)·분배 이력(KODEX)을 표시, 차트 캔들이 확정 일봉과 일치 |

스크린샷은 세션 검증용으로만 사용했고 저장소에 포함하지 않는다.

## 자동 검증 명령

```bash
cd frontend
bun run lint && bun run typecheck && bun run test
bun run e2e   # API :8000 + Vite :5173 필요
```

vitest 16건은 보조지표(SMA·RSI·MACD·볼린저) 수치 벡터, 시장 데이터 Zod strict 계약(계약 밖 필드 거부 포함), 수 표기 유틸과 운영 개요 렌더링을 검증한다.

## 남은 범위

- 관심종목과 전체 종목 검색은 종목 마스터 수집(현재 수집 대상 2종목 외) 이후 확장한다.
- 미국 시장 필터는 해당 단계 미도달로 이번 범위에서 제외했다.
- 차트 십자선·구간 선택·확대 상호작용은 미결정 사양으로 남아 있다.
- 라이트·다크 수동 고정 설정은 설정 화면에서 제공한다(현재 시스템 설정 추종).
