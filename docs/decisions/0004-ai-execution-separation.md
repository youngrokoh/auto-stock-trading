# ADR-0004: AI 신호와 주문 실행 분리

- 상태: 승인
- 결정일: 2026-08-11
- 관련 정책: [거래 안전 정책](../spec/trading-safety-policy.md), [모의투자·실전투자 전환 게이트](../spec/paper-to-live-gate.md)

## 배경

프로젝트는 공시를 분석하는 생성형 AI와 OHLCV·보조지표를 학습하는 머신러닝 모델을 포함한다. AI 출력은 비결정적이거나 표본 밖에서 성능이 저하될 수 있고, 주문은 자금 손실로 직접 이어진다.

## 결정

- AI는 구조화된 분석, 점수, 신뢰도와 근거만 생성한다.
- AI 서비스에 증권사 주문 자격증명을 제공하지 않는다.
- AI 출력은 주문 API에 직접 전달할 수 없다.
- 전략 엔진이 AI 신호를 목표 포지션 후보로 변환한다.
- 고정된 위험관리 엔진이 주문 한도, 잔고, 장 상태, 데이터 신선도를 검사한다.
- 주문 서비스만 증권사 주문 어댑터를 호출할 수 있다.
- AI를 완전히 비활성화해도 규칙형 전략과 주문 시스템은 동작해야 한다.

```text
AI 분석·예측
→ 전략 신호
→ 목표 포지션
→ 결정적 위험검사
→ 주문 계획
→ 증권사 API
```

## 대안

### LLM의 직접 주문

재현성, 설명 가능성, 안전 경계와 테스트 가능성이 부족하므로 금지한다.

### ML 모델의 직접 주문

모델 출력과 주문 수량·한도를 결합하면 모델 실패가 즉시 손실로 이어지므로 채택하지 않는다.

## 결과

- AI 모델 실패가 주문 안전 규칙을 우회하지 못한다.
- 주문 결정 근거를 신호, 위험검사, 체결까지 추적할 수 있다.
- AI 성능을 그림자 운용으로 독립 검증할 수 있다.
- 모델 신호와 주문 사이에 명시적인 전략 변환 계층이 필요하다.

## 재검토 조건

이 결정은 실전매매가 존재하는 동안 유지한다. AI가 주문 실행을 직접 통제하도록 완화하지 않는다.
