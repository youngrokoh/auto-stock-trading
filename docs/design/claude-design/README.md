# 화면 구현 요청 안내

- 상태: 승인된 디자인 구현 안내
- 승인일: 2026-08-12
- 구현 상태: 미착수

이 폴더의 두 파일은 사용자가 승인한 화면 디자인 계약과 시안이다. 화면 구현은 한 번에 전체를 요청하지 않고 아래 식별자를 기준으로 나눈다.

## 1. 파일 배치

```
docs/design/claude-design/screen-design-spec.md    화면 디자인 사양 (색상·타이포·컴포넌트·상태 규칙)
docs/design/claude-design/screen-mockups.html      시안 8턴 (단일 파일, 브라우저로 열림)
```

`screen-mockups.html`은 외부 의존성이 없는 단일 파일이다. 저장소에 그대로 커밋하고 브라우저로 열면 된다.

## 2. 시안 구성

| 턴 | 내용 |
|---|---|
| 1 | 디자인 방향 3안 비교. 1c Research Grid 채택 |
| 2 | 운영 개요, 기업 분석, 전략 연구·백테스트 |
| 3 | ETF 탐색과 순위 |
| 4 | 모의매매 콘솔 |
| 5 | 설정과 감사 로그 |
| 6 | 실전 전환 게이트 |
| 7 | 빈 상태와 차단 상태 |
| 8 | 다크 모드 |

각 옵션에는 `1c`, `4a`, `7b` 같은 식별자가 붙어 있다. 구현 요청 시 이 식별자로 화면을 지칭한다.

## 3. 구현 요청 프롬프트 예시

한 번에 전체를 요청하지 말고 화면 단위로 나눈다.

```
docs/design/claude-design/screen-design-spec.md 를 읽고
docs/design/claude-design/screen-mockups.html 의 4a
(모의매매 콘솔) 화면을 frontend 에 구현해줘.

- 사양서 2절 색상, 3절 타이포, 5절 컴포넌트 규칙을 그대로 따를 것
- 좌표 라벨(A1, B1, D1)은 시안에 있는 그대로 유지
- 4.1절 세로 공간 배분 규칙을 지킬 것. margin-top:auto 로 하단 요소를 밀지 말 것
- 데이터는 실제 API 연동 전까지 빈 상태로 두고, 사양서 7.3절 빈 상태 규칙을 적용
- 기존 frontend/src/styles.css 토큰 체계를 확장하는 방향으로 작업
```

## 4. 주의할 점

- 시안의 수치는 모두 레이아웃 검토용 예시값이다. 실제 데이터가 아니므로 그대로 하드코딩하지 않는다
- 제품 문서는 현재 단계에서 가짜 시장 데이터 표시를 금지한다. 구현 시 빈 상태로 시작한다
- 차단 사유 코드(사양서 7.2절)는 백엔드 응답과 화면이 같은 문자열을 써야 한다
- 위험 한도 값(사양서 6절 모의매매 콘솔)은 `trading-safety-policy.md`가 원본이다. 화면에 값을 직접 쓰지 말고 설정에서 읽는다

## 5. 미확정 항목
