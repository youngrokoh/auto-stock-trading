## 실제 수집 검증 (2026-08-17)

사용자의 OpenDART 키(`.secrets/dart-api-key`)로 삼성전자(`00126380`)를 수집했다.

| 항목 | 값 |
|---|---|
| 1차 수집 | 보고서 14건 저장(2021~2025 사업보고서, 2026 1분기·반기 × 연결·개별), 2026 3분기 2건 미제출 건너뜀 |
| 멱등 재수집 | 동일 결과(14 저장·2 건너뜀), 전 보고서 `version=1` 유지, 라인 수 불변 |
| 원문 대조 | 자산총계 — 2025 연결 사업보고서 566,942,110,000,000 / 2026 반기 연결 759,480,516,000,000(접수 20260814003699) / 2026 1분기 개별 404,509,604,000,000 — DART 원문 응답과 일치 |
| 라인 수 | 2025 연결 229행, 2026 반기 연결 223행, 2026 1분기 개별 137행 등 원문 응답과 일치 |
| 읽기 API | 보고서 목록 14건, 2025 연결 사업보고서 229라인(자산총계·매출 원문 값), 정정 이력, 미등록 종목 404 확인 |

## 실측으로 정정된 계약 항목 (사용자 승인)

- 자본변동표(SCE)는 같은 원문 순서(`ord`)를 자본 구성요소별 여러 행이 공유한다(예: 2021 사업보고서 `기말자본` ord=13 반복). 라인 유일키를 응답 순번 `(report_id, line_seq)`로 정정했다.
- `account_id` 실측 최대 길이 180자 — 컬럼 폭을 `VARCHAR(255)`로 정정했다.

## 재무 지표 계산 검증 (2026-08-17)

승인된 [재무 지표 정의 계약](../data/financial-indicator-contract.md)에 따라 저장된 삼성전자
연간 보고서(연결, 2021~2025)에서 지표를 계산하고 원문 금액으로 수동 재계산해 대조했다.

| 항목 | 값 |
|---|---|
| 계산 범위 | 연결 5개년 × 지표 9종 전부 값 생성 (성장성 3, 수익성 4, 안정성 2) |
| 2025 수동 대조 | 매출액증가율 (333,605,938−300,870,903)÷300,870,903×100 = 10.88% / 영업이익률 43,601,051÷333,605,938×100 = 13.07% / 부채비율 130,621,773÷436,320,337×100 = 29.94% — API 응답과 일치 |
| 공개 실적 대조 | 2024 매출 300.87조·영업이익 32.73조, 2023 매출 258.94조·영업이익 6.57조 등 원문 값이 공시 실적과 일치, 2024 영업이익증가율 398.34% |
| 개별(OFS) fail-closed | 지배주주 계정이 없어 ROE가 값 없이 `MISSING_ACCOUNT` 반환, 입력 금액은 전부 `null` |
| HTTP 오류 계약 | 미등록 종목 404, `fs_div=bogus` 422 확인 |
| 출처 노출 | 연도별 `rcept_no`·`version`, 지표별 수식·입력 계정·금액이 응답에 포함 |

## 기업 분석 화면 검증 (2026-08-17)

승인 디자인 2b(A 지표 KPI 7 / B 실적 차트·재무제표 / C 지표·가치 / D 수급·공시)를 승인
토큰·프리미티브로 구현하고 실제 브라우저로 확인했다.

- e2e 12건(운영 개요·시장 데이터·기업 분석·갤러리 × 모바일 390·태블릿 768·데스크톱 1360)
  통과: 콘솔 오류 0, 가로 넘침 없음, 연결 URL 미노출, 손익계산서 탭 전환, 개별 전환 시
  ROE "지배주주 계정 없음" 표시.
- 세 폭과 다크 모드 전체 페이지 스크린샷을 육안 확인: 태블릿 접기 규칙(레일 유지·내비
  숨김·1열·KPI 3열) 유지, 7번째 KPI는 태블릿·모바일에서 전체 폭으로 접힘, 재무제표 구분
  탭 줄바꿈 정상, 다크 토큰 일치.
- 백엔드가 없는 가치 지표·수급·공시 연결은 값 생성 없이 사유를 적은 빈 상태 카드다.
- 재무제표 카드의 금액은 DART 원문 라인 그대로이며(자산총계 566,942,110,000,000 표시
  확인) KPI의 조 단위 축약은 표시 전용이다.

## 자동 검증 명령

```bash
cd backend
uv run pytest tests/fundamentals tests/disclosures/test_opendart_financials.py \
  tests/api/test_fundamentals_api.py tests/worker/test_fundamentals.py
cd frontend
bun run test    # 지표 스키마·조/억 포맷 단위 테스트 포함
bun run e2e     # API :8000 + Vite :5173 필요
```

fixture·PostgreSQL 통합 테스트가 멱등 재수집, 접수번호 기반 정정 버전과 오래된 접수번호 거부, 미제출(013) 건너뜀, sync 상태 기록, 읽기 API 계약을 검증한다. 지표 단위 테스트는 고정 입력의 수치 벡터와 fail-closed 사유 4종(계정 없음·중복·금액 없음·분모 0)을 검증한다.
